# Security Policy / Sicherheitshinweise

## Reporting a vulnerability
Please do **not** open a public issue for security problems. Write to **kontakt@leckermath.de** with the subject "Security: german-tax-law-corpus". Describe the problem, the affected version and, if possible, a minimal example. Do not include real personal or client data in a report.

The maintainer confirms receipt within 7 days and informs you about the assessment and the planned fix. A fix is released as a new version and noted in `CHANGELOG.md`; reporters are credited if they wish.

## Supported versions
Only the latest released version receives fixes.

## Governance
The project has one maintainer (Sergei Sevriukov, LeckerMath, Dortmund), who decides on changes and releases. Contributions are welcome as issues and pull requests; each release is listed with its changes in `CHANGELOG.md` and tagged in git.
